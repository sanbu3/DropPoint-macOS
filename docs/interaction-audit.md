## Option 长按清空

1. 当前文件架必须已激活，且有内容。
2. 单独双击 Option，第二次按下后保持不放。第一下必须是短按，间隔使用 macOS 双击时间。
3. 底部横条变为 126 × 9 点的进度条；手柄外侧显示带 Option 键标识的短指引条，说明 1.2 秒清空、松开取消、保留文件架。使用单调时间计时，以 30 Hz 更新进度。
4. 连续按住满 1.2 秒后清空架内引用，保留空架和原始文件。该空架不触发自动关闭；再次加入文件后恢复正常空架关闭设置。
5. 松键、其他修饰键、普通按键、鼠标交互、滚动、切换窗口、拖入/拖出、隐藏或关闭均取消待完成手势。
6. 紧凑文件名和展开列表保持原有位置与亮度；指引为透明、无阴影、不接收鼠标、不抢焦点的子面板，靠近屏幕底边时改在上方显示，取消/隐藏/关闭时移除。减少动态效果时取消尺寸过渡，保留必要的进度反馈。

## 右键菜单

保留 AppKit 原生菜单交互，使用 14 点字体、18 点图标、230 点最小宽度；查看（含快速查看）、分享、复制/移动、转换/归档、自定义操作、废纸篓和文件架操作按分隔线分组。保留用户启用的操作及组内排序，无选中文件时禁用对应文件操作。紧凑、展开卡片及卡片边缘共用同一原生菜单；展开模式保留“从文件架移除”。

## Codex 图片拖入崩溃（2026-10-06 / 1.5.4）

本机两份 1.5.3 崩溃报告均为主线程 `EXC_BAD_ACCESS / SIGBUS`，栈经过 WebKit `WKMouseTrackingObserver`、SwiftUI `NSHostingView.hitTest` 和 `NSViewResponder.platformCurrentEvent` 的 executor 检查，错误地址落在 SwiftUICore 只读区。日志支持鼠标命中检测的框架兼容性路径这一判断，不能据此断言 Apple 内部的具体缺陷；故障栈未进入图片编码或写盘。此类内存访问崩溃无法用 Swift `do/catch` 捕获。

macOS 27 及后续版本的空架和拖入插图改用 AppKit 加载同一 SVG 的静态画面，移除文件架中的装饰性 WKWebView，避免其鼠标追踪回调进入问题路径；较早系统保留原 SVG 动画。原生拖入、拖出和移动区域优先由 AppKit 命中检测，使用实际 bounds 与可见区域共同约束，区域之外的关闭等控件保留 SwiftUI 路由。装饰插图显式禁用命中检测。

新增集成测试反复切换空架与拖入状态，检查 macOS 27 上不存在装饰性 WebKit 视图、原生插图可加载、中心命中原生拖入区域、关闭按钮未被接管，并通过该区域导入 TIFF 后验证 PNG 文件和文件架内容。原版本在程序化测试中没有稳定复现 SIGBUS，因此此测试验证规避措施与图片导入，不能等同于真实 Codex 鼠标拖动的崩溃复现。自动化工具禁止操作 Codex 自身窗口，真实“从 Codex 拖出图片”仍需用户重试。

最终全量 XCTest 80 项通过，0 失败；Universal Release（x86_64 / arm64）构建通过，浮动 UI 审查 0 error / 0 review item。已覆盖安装 1.5.4 / build 8 并严格验证本地签名；实际界面检查同一插图正常显示且不存在 WebKit HTML 元素、PNG 路径粘贴加入成功、右上角关闭按钮可关闭文件架、设置显示 1.5.4。检查完成后移除旧安装副本，仅保留最新版。验证日志保存在 `.build/Latest/Verification`。

## 窗口化与 Dropover 交互升级（2026-11-05 / 2.0.0）

目标是把应用收敛为纯浮动文件架，同时参考 Dropover 的产品结构补齐固定文件架、最近关闭、颜色标记与快捷操作栏。

### 窗口层

- 移除 `LSUIElement`，默认激活策略为 `.regular`，并在程序坞显示图标。设置中仍保留“在程序坞中显示”开关，关闭后可退回菜单栏模式。
- 不保留工作台或文件架中心主窗口；应用只使用浮动 `NSPanel`。点击程序坞图标显示/新建文件架，`applicationShouldHandleReopen` 也走同一路径。
- 删除了 `LibraryView`、`LibraryWindowController`、`LibraryModel` 与主窗口专属状态，避免出现第二份文件列表和状态分叉。
- `application(_:open urls:)` / `openFiles` 让 Finder、Dock 图标与“打开方式”把文件直接放入新文件架；同一次多文件打开会短暂合并后再建架，避免 LaunchServices 逐文件回调生成多个单项文件架。`Info.plist` 声明 `public.item` / `public.folder` 的 Alternate Viewer 文档类型。
- 启动、Dock 重新打开、`⌘N`、菜单栏和程序坞菜单统一接入浮动文件架；旧版本升级时一次性启用程序坞图标和启动文件架。

### 文件架身份与持久化

- `ShelfStore` 增加 `shelfName`、`ShelfTint`、`pinnedShelfID`。窗口标题、紧凑视图文件名标签、展开视图标题和颜色点同步更新。
- 新增 `PinnedShelf` 与 `RecentShelf`（Codable），保存在 `AppSettings` 的本地 `UserDefaults` 中。固定和最近记录只保存文件路径，不复制文件。
- 固定内容在文件增删、重命名、换色和改名后同步；清空文件架会自动移除对应固定记录。最近关闭最多保留 12 个，恢复时移除重复记录。
- 固定文件架、最近关闭以及菜单栏子菜单共用同一份数据。

### 交互

- 新增 `ShelfQuickActionBar`：展开文件架显示最多 4 个常用操作，并提供“更多操作”菜单。
- 鼠标按下文件架会激活窗口，避免文件架浮在其他应用窗口上方但键盘事件仍被抢走。
- 右键菜单新增重命名项目、上移/下移、打开方式、文件架重命名、颜色和固定；项目重命名使用同一文件夹内移动，冲突或失败时提示。
- 展开宽度固定 432 点，高度按行数 270/390/436；关闭快捷操作栏时减少 43 点。相关几何测试同步更新。
- 从紧凑文件架拖出时显示 `DragOutBoxView` 箱子动画、拖出数量和“松手放下”提示；该视图不接收鼠标，不干扰拖拽会话。macOS 27 上 WebKit 仍不使用，`AnimatedSVGView` 改为用 SwiftUI 时间轴驱动静态 SVG 的浮动/缩放/呼吸，保留动画并避开 WebKit 崩溃路径。
- 主快捷键默认改为新建文件架，并做一次性迁移，解决已有非空文件架时 ⇧Tab 只切换显隐的问题。
- 移除 `⌘K` 操作面板及 `ShelfCommand`/`ShelfCommandBarView`。
- 设置界面关闭系统聚焦效果，避免按钮、开关、选择器、滑块出现系统矩形聚焦框。
- 新增 `PermissionGuideWindowController` / `PermissionGuideView`：缺少输入监控权限时显示 Codex 风格悬浮引导窗，包含状态、四步操作、打开系统设置、重新检测、重新启动和稍后关闭。
- 新增双 Command 截图：`DoubleCommandMonitor` 检测左右 Command，`WindowScreenshotService` 用 ScreenCaptureKit 截取最近窗口，`ScreenshotFlyInPresenter` 用透明面板把截图飞入最近文件架；`ScreenRecordingPermissionService` 管理屏幕录制权限。
- 保持原有 Option 长按清空、双指手势、摇晃/修饰键唤出、Quick Look、贴边和“减少动态效果”行为。
