审查对象是当前工作区的 SwiftUI / AppKit 原生项目。保留原有未提交改动，在其基础上完成以下修复。

## 已修复的问题

| 优先级 | 触发场景与根因 | 修复 | 主要文件 |
| --- | --- | --- | --- |
| 高 | 目录更新时在主线程枚举全部文件、读取文件身份与截图元数据，大目录或慢文件系统会阻塞交互 | 所有扫描、过滤与身份比较放入串行 utility 队列；主线程只发布结果；停止或重启后丢弃旧回调；读取失败不覆盖有效基线 | `DirectoryWatcher.swift`、`AppDelegate.swift` |
| 高 | 浏览器拖入图片、剪贴板图片同步编码和写盘；文件承诺使用主队列且无完成期限 | 先快照粘贴板数据，后台编码、校验和写盘；普通导入、文件承诺使用独立队列，各限制并发为 2；承诺超过 60 秒提示失败并忽略迟到交付 | `FileDropImporter.swift`、`ClipboardService.swift` 及调用入口 |
| 高 | 加入文件时同步查存在性、读取每个文件的 Finder 图标；缩略图并发无上限 | 立即显示标准文件类型图标；后台验证文件与读取元数据，最多并发解码 2 项；取消后跳过排队解码，主线程丢弃旧结果；无法访问的项目移除并反馈 | `ShelfItem.swift`、`ShelfStore.swift` |
| 高 | 图片压缩输入直接把 Double 转成 Int，极大值或非有限值可能使进程崩溃 | 转换前检查有限性、正数、最小大小和 Int 上界 | `ShelfActionService.swift` |
| 中 | 下拉清空和键盘清空可启动两项重叠任务；关闭后待完成的任务可能更新旧架 | 两种清空互斥；关闭时取消动画和缩略图任务，拒绝迟到导入；拖出时固定原始选择并暂停预览，移动完成后只校验仍留在架内的文件；移除已不存在的引用不重复通知空架 | `ShelfStore.swift`、`ShelfWindowController.swift` |
| 中 | ZIP 子进程无限等待退出；自定义目录校验、图片类型过滤、拖出后源文件检查仍在主线程 | 耗时检查移到后台；归档子进程超过 300 秒终止，必要时强制结束 | `ShelfActionService.swift`、`ShelfStore.swift` |
| 中 | 无屏幕时强制解包、Quick Look 回调直接按索引访问，存在崩溃边界 | 屏幕使用可选值与安全回退；预览索引检查边界；Quick Look 不再同步检查文件存在性 | `ShelfWindowManager.swift` |

## Option 长按清空

1. 当前文件架必须已激活，且有内容。
2. 单独双击 Option，第二次按下后保持不放。第一下必须是短按，间隔使用 macOS 双击时间。
3. 底部横条变为 126 × 9 点的进度条；手柄外侧显示带 Option 键标识的短指引条，说明 1.2 秒清空、松开取消、保留文件架。使用单调时间计时，以 30 Hz 更新进度。
4. 连续按住满 1.2 秒后清空架内引用，保留空架和原始文件。该空架不触发自动关闭；再次加入文件后恢复正常空架关闭设置。
5. 松键、其他修饰键、普通按键、鼠标交互、滚动、切换窗口、拖入/拖出、隐藏或关闭均取消待完成手势。
6. 紧凑文件名和展开列表保持原有位置与亮度；指引为透明、无阴影、不接收鼠标、不抢焦点的子面板，靠近屏幕底边时改在上方显示，取消/隐藏/关闭时移除。减少动态效果时取消尺寸过渡，保留必要的进度反馈。

## 右键菜单

保留 AppKit 原生菜单交互，使用 14 点字体、18 点图标、230 点最小宽度；查看（含快速查看）、分享、复制/移动、转换/归档、自定义操作、废纸篓和文件架操作按分隔线分组。保留用户启用的操作及组内排序，无选中文件时禁用对应文件操作。紧凑、展开卡片及卡片边缘共用同一原生菜单；展开模式保留“从文件架移除”。
