# DropPoint 2.0：纯浮动文件架

## 目标

DropPoint 1.x 是一个以菜单栏和浮动面板为主的拖放暂存工具。2.0 保留并强化这个方向，不再引入工作台或文件管理主窗口：

- 应用只围绕浮动文件架
- 启动时可直接出现一个文件架
- 点击程序坞图标显示/新建文件架，而不是打开主窗口
- 固定文件架、最近关闭放在菜单栏子菜单
- 界面与交互参考 [Dropover](https://dropoverapp.com/)：文件架、固定、最近关闭、颜色标记、快捷操作

## 功能映射

| Dropover 能力 | DropPoint 2.0 实现 |
| --- | --- |
| 临时浮动文件架 | 摇晃/修饰键唤出、紧凑/展开、贴边和手势 |
| 命名与颜色标记文件架 | `ShelfTint` 六色；`···` 菜单与右键菜单改名、换色 |
| 固定文件架 | `PinnedShelf` 本地持久化；菜单栏子菜单 |
| 最近关闭 | `RecentShelf` 最多 12 个；菜单栏恢复 |
| 快捷操作 | 展开文件架内的 `ShelfQuickActionBar` |
| 管理文件 | 重命名、上移/下移、移除、用其他应用打开、分享、压缩、PDF、ZIP |
| 从 Finder 打开 | `application(_:open urls:)` + Alternate Viewer 文档类型 |
| 截图并放入 | 双 Command 截取最近窗口 + 飞入动画 |
| 菜单栏 | 新建、固定、最近关闭、设置 |
| 窗口化 | 文件架本身就是窗口；程序坞图标可见 |

没有实现云上传、账号、同步或第三方存储。

## 展开文件架的 UI

- 宽度固定 432 点，快捷操作栏不再被右侧圆角裁切
- 高度按行数：1 行 270、2 行 390、3 行以上 436
- 关闭“显示快捷操作栏”后，高度相应减少 43 点（227 / 347 / 393），不留空白
- 标题栏只保留返回、身份、菜单和关闭，Finder/移除操作放进快捷栏和右键菜单
- 选中文件不再显示底部横条；使用背景色、描边和勾选标记表示选中
- 双击标题重命名文件架
- 鼠标按下文件架会激活窗口，键盘操作始终进入当前文件架

## 双 Command 截图

- `DoubleCommandMonitor` 监听左右 Command 的 flagsChanged；本地监视器覆盖 DropPoint 激活时，全局监视器依赖输入监控权限
- 通过 `CGWindowListCopyWindowInfo` 选择光标下最近/最前的普通窗口，排除 DropPoint 自身和系统 UI
- `ScreenCaptureKit` 按窗口 ID 截图，保存到 `Application Support/DropPoint/Captures`
- 优先放入距离光标最近的文件架；没有可见文件架时在光标附近新建
- `ScreenshotFlyInPresenter` 用透明无阴影面板把截图从源窗口位置缩放到文件架中心
- 截图权限由 `ScreenRecordingPermissionService` 管理；设置页显示状态，首次截图时给出系统设置引导

## 交互修复

### 拖出箱子动画

从紧凑文件架拖出文件时，原文件堆叠淡出并显示箱子动画、拖出数量和“松手放下”提示；拖拽会话结束后恢复正常文件架。这个视图不接收鼠标，不会干扰 AppKit 拖拽会话。

两套 SVG 的完整时间线在开发时按 30 fps 采样为透明 Retina APNG，包含路径形变、眼睛、尾巴和箱盖动作；应用内由 ImageIO 读取帧时长，Core Animation 原生播放，不创建 WebKit 或逐帧刷新 SwiftUI。猫咪保持间隔播放，箱子播放一轮，减少动态效果时使用静帧。

### 新建快捷键

主快捷键默认改为“新建文件架”。一次迁移会把旧版默认的“显示/隐藏”改为“新建”，因此在已有非空文件架时按 ⇧Tab 会创建一个新的空文件架，而不是隐藏当前文件架。设置中仍可切回“显示/隐藏”。

### 设置聚焦框

设置界面关闭了系统聚焦效果（包括按钮、开关、选择器、滑块和侧栏），避免键盘导航时出现系统矩形聚焦框。

### 权限引导

从设置点击“权限引导”或“启用”，打开系统设置旁的小浮窗。应用图标可以拖入输入监控列表，由用户开启系统开关。浮窗不抢焦点，会跟随设置窗口移动，定时刷新权限并在关闭、授权生效或超时后退出。授权需要重启时提供重启按钮，先退出旧进程再启动新版，当前非固定文件架保存到最近关闭记录。

### 多文件打开

LaunchServices 可能按文件逐个回调 `open urls`。2.0 在 250ms 窗口内合并回调，一次打开多个文件只创建一个文件架，避免出现多个“只有 1 项”的文件架，以及由此导致的展开按钮不可用。

### 高度与设置联动

切换“显示快捷操作栏”时，已展开的文件架会即时重新计算高度，不会留下空白区域。

## 已知边界

- 屏幕合成效果（真实桌面透明材质、阴影）未用系统截图验证，因为当前环境没有屏幕录制权限；离屏渲染使用固定背景。
- 固定/最近记录保存路径，原文件移动或删除后需要重新固定。
